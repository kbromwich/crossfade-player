# Crossfade Player

https://kbromwich.github.io/crossfade-player/

A simple (vibe-coded) web audio player with configurable crossfade that plays
local files. Drag files into the page to make a playlist (they will).

### Why?
Other (web) players don't support cross-fade when manually changing tracks.
I wanted a simple tool to loop an individual track and then cross-fade when
manually changing to the next track (for use with background music in DnD).

I also wanted to test for myself how good models are getting at vibe-coding. 🤷
